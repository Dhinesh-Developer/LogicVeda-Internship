# 🚀 Real-Time Data Engineering Pipeline using Kafka & PostgreSQL

This project demonstrates a real-time data streaming pipeline using Apache Kafka, Python, and PostgreSQL. The system simulates live data generation, processes it through Kafka Producer–Consumer architecture, and stores it into a relational database.

---

# 🛠️ Tech Stack
- Apache Kafka (KRaft mode)
- Python (kafka-python, faker)
- PostgreSQL
- Jupyter Notebook
- Git & GitHub
